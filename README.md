# Axiom · 数学题库系统

> 极简 · 沉浸 · 优雅 —— 为数学教研与错题管理而生的本地题库系统。

Axiom 是一款**本地离线运行**的数学题库管理工具,采用乔布斯式的极简设计哲学:一个时刻只有一件事。内置 AI 识别、艾宾浩斯遗忘曲线错题重做、组卷排版等完整闭环。

---

## ✨ 功能特性

| 工作台 | 功能 |
|---|---|
| **题库研讨** | 全屏题目列表 + 全屏编辑器(单视图沉浸式)。支持手动录入、**OCR 图像识别**、**AI 智能解题/分类** |
| **错题重做** | 按**艾宾浩斯遗忘曲线**(1→2→4→7→15→30 天)自动安排重做时间;分题计时、结算报告、再战区、按教材/标签筛选复习 |
| **题库总览** | 购物式列表浏览全部题目,点击进入详情(题干/答案/评述/插图),一键加入错题本 |
| **组卷排版** | 四部曲组卷:配置筛选 → 题目流 → A4 画布预览 → PDF/LaTeX 导出 |
| **设置** | API 接口、自定义维度、界面主题(6 色)/深浅色、数据统计 |

其他亮点:
- **单视图沉浸模式**:预览看列表、录题进全屏编辑器,互不干扰
- **按题计时 + 结算报告**:每题用时、对错、几天后复习,一目了然
- **艾宾浩斯遗忘曲线可视化**:实时展示你的错题在复习进度上的分布
- **深浅色自适应**,公式 KaTeX 渲染,支持中文
- 全离线运行,数据保存在本地 SQLite

## 🚀 快速开始

### 环境要求
- Windows 10/11
- Python 3.9+(项目目录内已内置便携版 `python/`,**无需安装**)

### 启动方式
**方式一(推荐)**:双击项目根目录的 `启动题库系统.bat`,浏览器自动打开 `http://127.0.0.1:8000`。

**方式二(命令行)**:
```bash
cd Axiom题库1.0
python\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8000
```
然后浏览器访问 `http://127.0.0.1:8000`。

> 若 8000 端口被占用,启动脚本会自动释放;也可自行更换端口。

## 📖 使用指南

### 1. 题库研讨(录题与浏览)
进入「题库研讨」工作台,默认显示**全屏题目列表**:

- **搜索**:顶部搜索框按内容/来源/标签实时筛选
- **预览**:点击任意题目 → 进入全屏编辑器,查看/修改题干、答案、评述、插图
- **录题**:点「录题」按钮 → 全屏编辑器,支持三种录入方式:
  - **手动输入**:在编辑区直接填写 LaTeX 公式(`$x^2$`、`$$\frac{a}{b}$$` 等)
  - **OCR 识别**:上传题目截图,自动识别文字与公式(需在设置中配置 AI API Key)
  - **AI 解题/分类**:一键生成解析、自动匹配章节
- **筛选**:点「筛选」展开题型/难度/学段/章节/来源/排序条件
- 编辑完成后点「保存」,再点「← 列表」返回

### 2. 错题重做(艾宾浩斯遗忘曲线)
「错题重做」工作台左侧面板提供:
- **每日重做**:今日到期的题目,按遗忘曲线安排
- **筛选复习**:按教材(学段/章节/知识点)+ 标签筛选错题,自定义刷题
- **再战区**:每日重做中答错过的题,重点攻克
- **艾宾浩斯曲线**:可视化 6 阶段进度与记忆保持率

刷题流程:
1. 点击「开始复习/进入再战」,左侧面板自动收起,进入**沉浸刷题**
2. 每道题**自动计时**;答题后点「答对」或「答错」
   - 答对 → 进入下一复习阶段,间隔拉长
   - 答错 → 重置为第 1 阶段(明天再重做)
3. 全部刷完 → **结算报告**:每题对错、用时、几天后复习
4. 刷题中随时点顶部「自定义复习」按钮展开面板

### 3. 题库总览
点击左侧导航「总览」,浏览全部题目(购物式列表),点任意题进入详情页(完整题干/答案/评述/插图),可直接「加入错题本」。

### 4. 组卷排版
1. 配置栏选择筛选条件(学段/章节/知识点/难度/题型)
2. 题目流中把题加入试卷
3. 右侧 A4 画布实时预览(可一键收起/展开)
4. 导出 PDF 或 LaTeX 源码包

### 5. 数据统计
「设置 → 界面与统计 → 打开数据统计大屏」:题库总量、题型分布、月度录入日历等。

## 🔑 配置 AI 功能(可选)

OCR 识别、AI 解题、智能分类需要 API Key:

1. 打开「设置 → API 接口设置」
2. 填写密钥(任选其一或全部):
   - **DeepSeek**(AI 解题/解析):`https://platform.deepseek.com`
   - **阿里云百炼**(OCR 识别,推荐):`https://dashscope.aliyuncs.com`
   - **硅基流动**(OCR):`https://cloud.siliconflow.cn`
3. 选择默认引擎与模型,保存即可

也可直接编辑项目根目录的 `.env` 文件。

## ❓ 常见问题

**Q: 双击 bat 没有反应/闪退?**
检查杀毒软件是否拦截;或在命令行运行 `启动题库系统.bat` 查看错误日志(`.system_generated/server.log`)。

**Q: 页面显示旧版本?**
按 `Ctrl+Shift+R` 强制刷新(浏览器缓存)。

**Q: 公式显示为源码 `$x^2$`?**
确认题目内容使用标准 LaTeX 包裹;AI 生成的裸环境(`\begin{aligned}` 等)已自动转换,若仍异常请检查内容格式。

**Q: 深色模式下文字看不清?**
点击「设置 → 界面与统计 → 显示模式」切换深浅色;系统默认跟随手动选择。

**Q: 数据存在哪里?**
全部在 `math_question_bank.db`(SQLite)。`data_backup/` 会定期导出 JSON/Markdown 备份。

**Q: 如何迁移/备份?**
直接复制整个项目文件夹即可;数据库与导出备份都在其中。
